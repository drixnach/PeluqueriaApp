# PeluqueriaApp

> Sistema de gestión para peluquerías y barberías: agenda de turnos, historial de clientes y comisiones en un solo lugar.

**Integrantes:** Francisco Gomez · Ignacio Moreyra

## Estructura del proyecto

El repositorio está dividido en tres partes:

| Carpeta | Descripción | Tecnologías |
|---------|-------------|-------------|
| `Backend/` | Proyecto de API web que expone los servicios y la lógica del negocio. | .NET 8 (ASP.NET Core Web API), Entity Framework Core con SQL Server, autenticación JWT, Swagger |
| `Frontend/` | Página web del proyecto. | React con Vite |
| `PeluquerosApp/` | Aplicación móvil para peluqueros y barberos. | Expo / React Native |
